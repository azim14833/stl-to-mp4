Common 3D Print Problems and How to Fix Them

Most failed prints come from a short list of causes. This guide groups the common ones by symptom so that you can change one thing at a time and see what helps. It describes FDM printers that melt plastic filament; resin printing has different problems.

The first layer does not stick

Likely causes: bed not level, nozzle too far from the bed, dirty build surface, bed too cold. Try: re-level or run the printer's automatic levelling, clean the plate with isopropyl alcohol, lower the first-layer height slightly and use the bed temperature recommended for the filament. Print the first layer slower.

Corners lift (warping)

Plastic shrinks as it cools. Materials such as ABS and ASA shrink more than PLA. Try: a brim, a heated bed, no draughts, an enclosure for high-shrink materials, and rounded corners in the design.

Thin strings between parts (stringing)

Molten plastic oozes during travel moves. Try: dry the filament, lower the nozzle temperature by 5 to 10 degrees, enable retraction and tune its distance and speed, and increase travel speed.

Gaps, thin walls or rough surfaces (under-extrusion)

The printer is not delivering enough plastic. Try: check for a partial clog, make sure the filament path is free, verify the flow rate and raise the temperature a little. Damp filament also causes it.

Layers shifted sideways

Usually a mechanical issue: loose belts, a collision with a curled print, too fast acceleration, or a loose pulley. Try: check belt tension, lower speed and acceleration, and use a lower travel height or Z-hop where parts curl.

Drooping overhangs

Plastic has nothing to rest on. Try: rotate the model, add supports, increase part cooling, or print slower on the overhanging layers. See Best 3D Print Orientation.

Parts crack along layer lines

Weak layer bonding. Try: print hotter, reduce cooling fan speed for functional parts, and orient the part so the load does not pull layers apart. Add wall loops rather than only infill.

Blobs and zits

These appear where each layer starts and ends. Try: set the seam position to the back or a hidden corner and tune retraction.

A simple way to debug

  1. Change one setting at a time.
  2. Print a small test shape instead of a long model.
  3. Keep filament dry; store it in a sealed box with desiccant.
  4. Write down what worked for each material.

Frequently asked questions

How do I know whether the model or the printer is at fault?

Slice and print a known good calibration model. If it prints well, inspect the file for holes and thin walls, as described in How to Check an STL File Before You Print.
