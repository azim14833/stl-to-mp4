STL vs 3MF vs OBJ vs PLY: Which 3D File Format Should You Use?

Four file formats cover almost everything makers exchange: STL, 3MF, OBJ and PLY. They look interchangeable because each can describe a triangle mesh, but they differ in what else they carry (units, colour, textures, print settings), in how big the files get and in what can go wrong when someone else opens them. This guide compares them feature by feature, adds measured file sizes for the same mesh, and ends with a decision table by use case.

Written and tested by Azim, creator of STLtoMP4, who publishes 3D models and preview media on Cults3D. Quick answer

  • Printing a single-colour part: STL works everywhere, but 3MF is smaller and carries units.
  • Multi-colour or multi-material printing: 3MF.
  • Sharing a textured or painted model for rendering: OBJ (with its .mtl and texture images) or glTF.
  • Storing a coloured 3D scan: PLY (vertex colours).
  • Selling or publishing a model: offer STL for compatibility and 3MF for convenience, and zip them.

STL

The oldest and most widely understood format. It stores only triangles and their normals. There is no unit: a cube that is 20 units wide might be 20 mm in one program and 20 inches in another, which is the origin of many “my model is tiny” problems (see scale and units). It also has no colour and no notion of several parts. Its great strength is that every slicer and viewer opens it.

3MF

Created as a modern replacement for STL for 3D printing. A 3MF file is a zip archive containing an XML description of the mesh, which can include units, colours, materials, several objects and print-related metadata. Because it shares vertices and compresses, files are small. Current slicers such as PrusaSlicer, Cura, OrcaSlicer and Bambu Studio open it; some older tools do not.

OBJ

A text-based format from the world of 3D graphics. It shares vertices, supports polygons beyond triangles and can reference materials and texture images through a companion .mtl file. The three-file arrangement (.obj, .mtl and images) is the usual source of problems: if the companion files are missing, the model opens without colour. OBJ has no units.

PLY

Created for storing 3D scan data. It handles per-vertex colour well and exists in a compact binary variant. It is less common in printing software, but good for colour scans and for research tools.

The pattern is clear. STL repeats every corner point for every triangle, while OBJ, PLY and 3MF store each point once. 3MF adds compression and was the smallest in all four of our tests. For a smooth mesh of the same triangle count the 3MF was only 16% of the binary STL. See how to reduce STL file size for more on this.

Frequently asked questions

Is 3MF better than STL?

For most modern printing workflows, yes: smaller, with units and colour. STL remains the safest choice for compatibility with old software and with buyers you do not know.

Can STL store colour?

The original format cannot. Some programs write colour into unused bytes of binary STL, but there is no standard and many tools ignore it. Use 3MF, OBJ or PLY for colour.

How we measured

The test mesh is a UV sphere of 20 mm radius with 316 x 320 segments and Gaussian noise of 0.05 mm standard deviation added to each vertex radius, giving 201,608 triangles and 101,120 vertices. OBJ uses six decimals, PLY uses float32 positions and int32 indices, 3MF uses six significant digits in XML with DEFLATE compression and ASCII STL uses %e formatting. Real models differ; the raw numbers are in a CSV file.
